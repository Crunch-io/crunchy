# crunch + shiny = crunchy

`crunchy` makes it easy to build Shiny apps with data stored in the [Crunch.io](https://crunch.io/) cloud data service. You can run these apps locally, or you can host them on Crunch.

See `inst/demo_auth/explanation.md` for some of the details of how shiny applications work on the crunch infrastructure.

Contact us to find out more about how to get access.

## Installing

The package is not on CRAN, and so can be pulled from GitHub using the [remotes](https://remotes.r-lib.org/) package:

```r
# install.packages("remotes")
remotes::install_github("Crunch-io/crunchy")
```
